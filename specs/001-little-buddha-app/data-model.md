# Data Model (Firebase / Firestore)

## Firestore Collections

### `users` (Collection)
> Document ID: matches the Firebase Auth `uid`

Stores extended profile information about the user that isn't captured by Firebase Auth's standard fields.
- **name** (`String`): The user's given or Buddhist name.
- **birth_year** (`Number`): Used by security rules and the client to calculate their target tier.
- **createdAt** (`Timestamp`): When the account was registered.

### `lessons` (Collection)
> Document ID: Auto-generated by Firestore

Stores the educational content. Security rules constrain read access based on the `targetAgeTier`.
- **title** (`String`): Display title of the story.
- **textContent** (`String`): The story body.
- **targetAgeTier** (`String`): Must be one of `0-7`, `8-12`, `13-18`. Used by security rules to grant document read access to users of appropriate ages.
- **audioRef** (`String`): Path to the audio file in Firebase Cloud Storage (e.g., `audio/lessons/buddha_birth.mp3`).
- **summaryPoints** (`Array<String>`): Bullet points summarizing the moral.
- **discussionQuestions** (`Array<String>`): Questions to prompt reflection.
